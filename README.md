# Spotify Music Catalogue (Simple Python Project)

A simple, menu-based Python project for running in VS Code. It uses a CSV file as its dataset.

## Music categories
- Bollywood
- Sufi / Qawwali
- DHH / Rap
- Punjabi
- Indie
- Pop
- Ghazal

## Features
1. View all songs
2. Browse songs by genre
3. Search by song, artist, or album
4. View songs by an artist
5. Show top 10 songs by streams
6. Show genre-wise song count
7. Add a new song (saved to songs.csv)

## Run in VS Code
Open this folder in VS Code, then run these commands in the terminal:

```bash
python -m pip install pandas
python main.py
```

## Dataset note
This is a starter dataset for learning Python and pandas. Stream counts and average listening percentages are illustrative sample values, not verified live Spotify statistics. The project does not connect to Spotify or play audio.

## CSV columns
genre, artist, track_name, album_name, release_year, album_type, bpm, number_of_streams, song_length_min, avg_percent_song_played
